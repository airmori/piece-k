# ガクチャン HP 運営マニュアル

ガクチャン（https://gakuchan.jp ）のホームページを更新する手順です。

---

## 1. VSCode を開く

デスクトップまたはスタートメニューから **Visual Studio Code** を起動します。

## 2. フォルダを開く

「ファイル」→「フォルダーを開く」から以下を選択：

```
Desktop → github → gakuchan
```

## 3. Claude を起動する

「ターミナル」→「新しいターミナル」を開き（ショートカット: `Ctrl + @`）、以下を入力して Enter：

```
claude
```

前回の続きをしたいときは `/resume` と入力してください。

## 4. やりたいことを伝える

日本語でそのまま伝えればOKです。

- 「新しいイベントを追加して」
- 「トップページの文章を変更して」
- 「〇〇の写真を追加して」

Claude が変更を提案してくれるので、内容を確認して承認してください。

## 5. パソコンで確認する

Claude に「ローカルで確認したい」と伝えると、確認用のページを立ち上げてくれます。

ブラウザで http://localhost:4321 を開いて、変更内容を確認してください。

## 6. 公開する

確認が済んだら Claude に「公開して」と伝えてください。

数分後に https://gakuchan.jp に反映されます。
